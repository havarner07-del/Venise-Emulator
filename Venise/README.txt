VENISE
======

Double-click Venise.exe to start.

Keep Venise.exe and resources.neu together in this folder.
You can move the whole Venise folder anywhere, like C:\Games\Venise.
For a desktop icon: right-click Venise.exe > Send to > Desktop (create shortcut).

Data\Scripts  your scripts (they show in the sidebar)
Data\Images   pictures for the Press me button
Data\Game     your game as main.lua
Server         the multiplayer server

Multiplayer: install Node.js, then run  node Server\venise-server.js
Players connect to the address it prints (see the Multiplayer.lua example).

If Windows shows "Windows protected your PC", click More info > Run anyway.
Venise needs Microsoft Edge WebView2, which comes with Windows 10 and 11.
